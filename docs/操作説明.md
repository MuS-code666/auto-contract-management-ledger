# 操作説明

## 1. 最初に行う設定（「設定」画面）

1. **自社名・別名**: 自社の正式名称と略称（例：「架空建設株式会社」「架空建設（株）」）を1行に1つ入力して保存します。当事者の「当社／相手方」の判別に使います。未設定の場合、当事者はすべて「要確認」になります。
2. **カテゴリー**: 初期値（廃棄物処理関連、解体工事関連、設備・車両、不動産、業務委託、秘密保持、その他）を必要に応じて追加・名称変更・無効化します。カテゴリー名はPDFの保存フォルダ名になります。「キーワード」はカテゴリー候補の判定に使います。
3. **PDF保存ルート**: 既定は `data\契約書`。変更する場合は「新規保存先のみ変更」か「既存PDFも移行」を選びます。
4. **OCR・LLM**: 「OCRの動作確認」「LLMの動作確認」で利用可否を確認します。使えない場合は理由と対処が表示されます。

## 2. 契約書の取込み（「取込み」画面）

1. PDFをドラッグ＆ドロップするか「ファイルを選択」で1件選びます。元のファイルは変更・削除されません。
2. 同じPDF（ハッシュが同じ）が既に登録されている場合は、管理番号が表示され新規登録できません。
3. 解析が始まり、処理段階（文字情報の確認 → OCR → 項目抽出）と経過時間が表示されます。待たずに入力したい場合は「中止」を押すと手動入力に進めます。
4. 解析が終わると、左にPDF、右に抽出項目が表示されます。
   - **赤枠**＝要確認、**黄色**＝未確認の抽出値、**青**＝修正済み。
   - 各項目の下に根拠（「p.3へ」ボタン、既存テキスト由来／OCR由来、原文の引用）と注意事項が表示されます。「p.○へ」でPDFの該当ページへ移動します。
   - 左上のページ番号（緑＝既存テキスト、青＝OCR、赤＝未処理・低品質、灰＝空ページ）を押すと、そのページで取得した文字を確認できます。
5. 内容を確認・修正します。
   - 値が空のときは、右上の「状態」で **記載なし**（契約書に書かれていない）／**要確認**／**読取不能** を選べます。未入力とは区別して管理されます。
   - 日付は原文の表記（例：令和6年3月15日）と、正規化した日付を別々に持ちます。
   - 当事者（法人・個人）と署名者・代表者は別の欄です。署名者は所属する当事者を選びます。
   - 「通知期限の候補」は条文から計算した値と計算方法です。条文を確認したうえで「この候補を確定値に入れる」を押すか、「通知期限（確定）」に直接入力します。
6. 入力内容は自動で下書き保存されます（「下書き保存」ボタンでも保存）。画面を閉じても「取込み」画面の「下書き・取込み途中」から再開できます。
7. 「登録を確定」で管理番号（C000001 形式）が採番され、PDFが `保存ルート\カテゴリー\C000001_契約書名_相手方名.pdf` にコピーされます。
   - 契約名・当事者・契約日が似た契約があると「重複の可能性」が表示されます。再スキャンではなく別の契約（変更覚書など）であることを確認し、「重複候補を確認した」にチェックして登録します。
   - 解析中は登録できません（解析途中の内容を確定情報にしないため）。

紙だけの契約などPDFが無い場合は、「契約一覧」の「PDFなしで手動登録」から登録できます。

## 3. 契約一覧

- キーワード（契約名・当事者・要旨・管理番号・備考）、カテゴリー、種類、担当、確認状態、自動更新、期限の区分、期間指定（契約日・有効期限・通知期限など）で絞り込めます。
- 見出し（管理番号・契約書名・契約日・有効期限・通知期限）を押すと並べ替えます。
- 表示: 「—」＝未入力、「記載なし」、「要確認」、「候補」（アプリの計算値・未確定）を区別しています。
- 「検索結果をExcel出力」「全件をExcel出力」で .xlsx を保存します。

## 4. 契約詳細

- 登録内容とPDFを並べて表示します。「編集」で修正できます（修正は履歴に残ります）。
- 「未確認／要確認／確認済み」で確認状態を変更します（確認日時が記録されます）。
- カテゴリーを変更すると、PDFは新しいカテゴリーのフォルダへ移動します。ファイル名は初回登録時のまま変わりません。
- **関連契約**: 相手の管理番号と関係（基本契約→個別契約、原契約→変更覚書 など）を選んで「関連付け」。関連付けても元の契約の内容は変わりません。覚書で期限が変わった場合は、確認のうえ「管理上の期限」と根拠を入力してください（元の有効期限も残ります）。
- **削除**: 論理削除です。PDFは削除されず、一覧の「削除済み」で表示して「復元」できます。

## 5. 期限・要確認

期限経過、期限が近い、通知期限経過、通知期限が近い、日付未確定、要確認、確認予定日 の一覧を表示します。事前表示の日数は設定画面で変更します。自動更新の契約でも、時刻の経過だけで「更新された」とは扱いません。

## 6. Excel出力

- 日付列は日付形式、未確定の通知期限は「候補: …（未確定）」として確定値と別の列に出力します。
- 「記載なし」「要確認」は赤字で表示します。見出し固定・フィルター・折返しを設定済みです。
- 「PDFを開く」リンクは出力したPC上の保存場所を指します。別のPCや保存先の変更後は開けないことがあります。
- 契約書由来の文字列は数式として扱われないよう処理しています。
- Excelで編集した内容はアプリに取り込めません。

## 7. バックアップ・復元

- 「設定」→「今すぐバックアップ」で、台帳・設定・抽出結果・PDF・下書きを `data\backups\backup_日時.zip` に保存します。作成後に内容（ハッシュ）を自動検証します。
- 別の場所（外付けドライブなど）にもコピーして保管してください。
- 復元: 一覧の「復元…」→ 内容と影響を確認 → バックアップ名を入力して実行。実行前に現在のデータを「復元前自動バックアップ」として保存します。復元後、PDFの参照を検証して結果を表示します。
- PDFの保存場所が変わる場合（別PCへの移行など）は「復元先の指定」にフォルダを入力します。

## 8. 困ったとき

| 表示 | 対処 |
|---|---|
| パスワードで保護されたPDF | パスワードを解除したPDFを用意して取り込みます |
| PDFとして読み込めません | スキャンし直すか、別のソフトでPDFを保存し直します |
| ページ数／サイズが上限を超えています | PDFを分割するか、設定で上限を見直します |
| 読み取れていないページがあります | OCRの設定を確認するか、該当ページを手で入力します（「記載なし」とは判断しません） |
| LLMサーバーに接続できません | `start_llm.bat` を起動してから「LLMの動作確認」 |
| ディスク容量が不足しています | 空き容量を確保して再実行します |
| 前回中断したファイル操作を整合させました | 起動時に自動で復旧しています。「設定」→「整合性チェック」で状態を確認できます |

エラーの詳細は `data\logs\app.log` に記録されます（契約本文・当事者名は記録しません）。
