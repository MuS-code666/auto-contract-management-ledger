## 採用しなかったもの

- PyMuPDF：AGPL-3.0（または商用ライセンス）のため、社内配布時の条件を避けるため不採用。
- クラウドOCR・外部生成AI API：要件（契約情報を外部へ送信しない）により不採用。

## サンプルPDF

`samples\` のPDFは本アプリのスクリプトで生成した架空の文書です。フォントは reportlab の CID フォント（HeiseiMin-W3、埋め込みなし）を参照しています。
