## 5. 実LLMの検証手順（未実施）

開発環境では llama.cpp（b12058 CPU版）と Qwen3-4B-Instruct-2507 Q4_K_M（SHA-256 一致）を取得したが、外部から取得したサーバー実行ファイルの起動が開発環境のポリシーで許可されなかったため、実LLMでの検証は行っていない。次の手順で検証できる。

```
start_llm.bat
set LEDGER_LLM_URL=http://127.0.0.1:8081/v1
.venv\Scripts\python -m pytest -m real -v
.venv\Scripts\python scripts\evaluate.py --set all --ocr rapidocr --llm openai_compat --out docs\eval_llm.json
```

確認すべき点: 項目ごとの正誤・欠落（ルールのみの結果と比較）、誤りが「要確認」なしで出ていないか、1文書あたりの処理時間、メモリ使用量、サンプル07の命令文の影響、JSONスキーマ違反の発生頻度。
